# pairwise-ledge-climbing

角色抓边时手已经抓住 ledge，身体还在往下掉，检测只从胶囊前方打一条射线，没检查 ledge 上方是否有足够空间；攀爬状态机在高度差小于阈值时反复切换，角色在边缘抖成上下踏步；根运动和攀爬位移同时叠加，角色穿进墙里；两个角色同时抓同一段 ledge，没有占用标记，身体互相穿插；网络预测的攀爬点和服务器不一致，客户端爬上去又被拉回；低帧率下动画事件丢失，角色停在半空；斜面 ledge 的法线没投影到水平面，角色悬空；取消攀爬时重力速度没清零，恢复后直接弹射；存档只存位置不存攀爬状态，读档后角色挂在墙外；攀爬碰撞层和相机碰撞层共用，镜头被 ledge 挡住。gameplay/ledge_climbing.py 是核心，tests/test_ledge_climbing.py 15个红。要修的是：检测加空间与上方净空；状态机加滞回；根运动剥离攀爬位移；ledge 占用锁；服务器权威攀爬点；动画事件按时间采样；斜面法线投影；取消时清速度；存档补攀爬状态；碰撞层分离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
